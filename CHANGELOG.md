## [0.1.0] - 2026-10-24

### Добавлено

- Поиск НПА на publication.pravo.gov.ru по реквизитам, полному названию или
  `eoNumber`: кэш органов, нормализация номеров, отбор по дате, совместные
  документы, поиск по цифровой части номера, диагностика `not_found`.
- Скачивание PDF с проверкой целостности; единая база SQLite.
- Справочники ИТС НДТ с burondt.ru: обход диапазона карточек, поиск по
  обозначению, году и номеру, Word-версии.
- Текст действующей редакции из EBPI в DOCX; связи с актами-поправками;
  кэш отрицательного результата со сроком действия.
- DOCX из текстового слоя PDF для документов, которых нет в EBPI.
- Документы старше границы охвата портала — текст из ips.pravo.gov.ru
  (статус `found_text_only`).
- Веб-приложение: единый поиск, предпросмотр DOCX, распознавание сканов через
  сервис npa-ocr, мониторинг ресурсов сервера (`/monitor`).
- Docker-образ веб-приложения; порт задаётся `WEB_PORT`;
  `docker-compose.dev.yml` для разработки npa-ocr без пересборки образа.

### Изменено

- OCR выделен в отдельный проект npa-ocr и подключается как HTTP-сервис.

### Исправлено

- Редакции EBPI с датой вступления в силу в будущем не выбираются.
- Результат распознавания скачивается, даже если на диске уже есть .docx
  предыдущего распознавания того же документа.
- Разбор названия с опечаткой «от от».
