# Правила интеграции OCR

- Передавать пользователю автоматический результат сервиса npa-ocr.
- Запрещены ручные/точечные правки результата и индивидуальные подстановки
  для конкретного документа. Ошибки устраняются общими правилами кода.
- Нерешённые ошибки документировать в `docs/open-questions.md` и согласованно
  с открытыми вопросами npa-ocr: рукописный текст; `[не распознано]`;
  мелкие ошибки, не меняющие смысл документа.
- Ручная сверка допустима только для диагностики и тестовых эталонов.
